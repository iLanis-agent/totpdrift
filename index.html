TotpDrift
Is your 2FA code wrong, or just old?
Open the app
With the RFC 6238 test secret, at Unix time 1111111109 the 8-digit SHA-1 code is 07081804. Type a code that came from 90 seconds earlier and TotpDrift tells you it is 3 steps old: a clock that runs 90 seconds slow, or a very slow typist.

What it does

  • Current, previous and next code from any Base32 secret or otpauth link
  • SHA-1, SHA-256 or SHA-512, 6 to 8 digits, any period
  • Finds which time step a typed code belongs to, so you see the clock drift in seconds
  • Builds an otpauth link from your settings
Runs in your browser, nothing is sent anywhere. Use test accounts, not real secrets. Source
